# Translating Immersion

Immersion has interface catalogs for English (`en`), Serbian in Cyrillic (`sr`), French (`fr`), Spanish (`es`), Greek (`el`), and German (`de`). Users can choose a language on the first onboarding screen or in **Settings → Language**. The choice is stored as `language` in the app settings and takes effect immediately.

## Edit a translation

The JSON catalogs are in [`crates/immersion/locales`](../crates/immersion/locales). Each file has the same keys. `en.json` is the source text; edit only the values in the language you are translating. For example:

```json
"onboarding.back": "Retour"
```

Keep placeholders such as `{count}`, `{folder}`, and `{version}` exactly as written. You may move them within a sentence to fit the grammar. Use `\n` for a line break and keep file names and paths such as `.musit` and `.immersion/settings.json` unchanged. Choose short labels that fit buttons and dropdowns. In German, prefer short phrases over long compound nouns when they read naturally.

The catalogs cover app controls, onboarding, dialogs, menus, dates, and notifications. Project names, paths, diagnostic activity logs, and messages generated by the backend retain their original text.

## Add a language

1. Copy `en.json` to a new file named with a short language code, then translate every value.
2. Add the catalog to [`src/i18n.rs`](../crates/immersion/src/i18n.rs): create a `OnceLock`, load it with `include_str!`, and add its code to `LANGUAGES`, native name to `LANGUAGE_NAMES`, and lookup to `tr`.
3. Add the code to the accepted languages in [`AppBackend::set_language`](../crates/musit-core/src/backend.rs) and `app_language_from_root` in [`project_registry.rs`](../crates/musit-core/src/project_registry.rs). Unknown codes must continue to fall back to English.
4. Run `cargo fmt --all --check`, `cargo test --workspace --locked`, and `cargo build --workspace --locked`. The catalog test checks matching keys and placeholders. Inspect the onboarding and Settings controls on macOS and Windows for clipped text.

Do not translate stored sort or folder-layout values; the UI displays translated labels while keeping those internal values stable.
